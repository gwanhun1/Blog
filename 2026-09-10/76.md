# ChatGPT Images 2.5 출시: Flare·Sunburst가 바꾸는 AI 이미지 편집 워크플로

AI에게 제품 사진 속 빨간 머그잔만 파란색으로 바꿔 달라고 해보자.

머그잔 색은 바뀌었는데 모델의 얼굴도 조금 달라진다. 손가락 위치가 흔들리고, 멀쩡하던 로고의 철자가 틀리며, 조명은 전혀 다른 시간대처럼 변한다. 첫 결과는 멋있지만 두 번째 수정부터 원본이 무너지기 시작한다.

그동안 AI 이미지 생성의 고질적인 문제는 **원하는 것을 만들지 못하는 것**보다 **요청하지 않은 것까지 바꿔 버리는 것**에 가까웠다.

2026년 9월 8일 공개된 ChatGPT Images 2.5가 흥미로운 이유도 여기에 있다. OpenAI는 더 선명한 디테일이나 자연스러운 조명뿐 아니라, 참조 이미지 속 인물과 피사체를 유지하는 능력, 여러 차례 이어지는 편집의 일관성을 전면에 내세웠다. API에는 용도가 다른 `GPT-Image-2.5 Flare`와 `GPT-Image-2.5 Sunburst`도 함께 등장했다.

이번 발표는 단순히 “그림을 더 잘 그리는 모델”의 출시가 아니다. AI 이미지가 일회성 생성 도구에서 **상태를 유지하는 편집 시스템**으로 이동하고 있다는 신호다.

## 이미지 생성의 새 기준은 ‘불변 조건’이다

텍스트 모델로 코드를 수정할 때 우리는 이미 비슷한 문제를 경험한다. 버그 하나를 고치라고 했는데 관계없는 파일까지 리팩터링하면 결과가 아무리 세련돼도 좋은 수정이라 부르기 어렵다. 이미지 편집도 마찬가지다.

예를 들어 쇼핑몰이 모델 착용 사진 100장에서 셔츠 색상만 바꾸려 한다고 해보자. 다음 요소는 편집 대상이 아니다.

- 모델의 얼굴과 체형
- 옷의 주름과 재질
- 카메라 각도와 구도
- 배경과 그림자
- 브랜드 로고와 제품 형태

바뀌어야 하는 것은 색상 하나뿐이다. 즉 성능은 새 픽셀을 얼마나 근사하게 만들었는지가 아니라, **수정 범위 밖의 픽셀을 얼마나 안정적으로 보존했는가**로 평가해야 한다.

OpenAI는 Images 2.5에서 참조 이미지의 피사체 보존과 멀티턴 편집 신뢰도를 개선했다고 설명한다. 여기에 이미지 위에 직접 의견을 남기는 댓글 편집, 스케치를 이미지로 바꾸는 Sketch, 반복 작업을 빠르게 시작할 수 있는 Templates가 추가됐다. 자연어 프롬프트가 빈 캔버스의 시작 버튼을 넘어, 작업 내역을 이어 가는 편집 인터페이스가 된 셈이다.

다만 “개선됐다”는 발표와 내 서비스에서 “충분히 안정적이다”는 판단은 다르다. 얼굴, 로고, 제품 라벨처럼 작은 변화도 실패로 이어지는 영역이라면 자체 테스트가 반드시 필요하다.

## Flare와 Sunburst, 무엇을 골라야 할까

API에는 두 모델이 제공된다. 이름만 보면 Sunburst가 상위 모델이고 Flare가 저가 모델처럼 보이지만, 실제 선택 기준은 조금 더 현실적이다.

| 모델 | OpenAI의 포지셔닝 | 먼저 시험할 작업 |
| --- | --- | --- |
| `gpt-image-2.5-flare` | 일상적인 고품질 생성에 최적화된 빠른 기본 모델 | 썸네일, 소셜 콘텐츠, 시안 탐색, 상품 이미지 대량 변형 |
| `gpt-image-2.5-sunburst` | 여러 번의 편집에서 더 정밀한 제어를 지향하는 고성능 모델 | 캠페인 최종본, 브랜드 자산, 제품 비주얼, 수정 실패 비용이 큰 작업 |

OpenAI는 Flare가 GPT-Image-2보다 더 높은 품질을 제공하면서 지연시간은 최대 50% 낮췄다고 밝힌다. “최대”라는 표현은 조건에 따라 결과가 달라질 수 있는 공급사의 측정치라는 점을 기억해야 한다.

공개된 모델 문서상 Flare와 Sunburst의 토큰 단가는 동일하다. 텍스트 입력은 100만 토큰당 5달러, 이미지 입력은 8달러, 이미지 출력은 30달러다. 하지만 가격표가 같다고 실제 작업 비용까지 같은 것은 아니다. 생성 시간, 재시도 횟수, 검수자의 수정 시간까지 합쳐야 하기 때문이다.

```text
실제 이미지 한 장의 비용 =
  API 사용료
  + 실패한 생성 횟수
  + 사람이 비교하고 수정하는 시간
  + 잘못된 결과가 공개됐을 때의 비용
```

따라서 처음부터 모든 요청을 Sunburst로 보내는 방식은 단순하지만 좋은 설계는 아니다. 대량 초안은 Flare로 만들고, 브랜드에 직접 노출되는 최종 결과나 반복 편집에서 원본 보존이 중요한 작업만 Sunburst로 올리는 편이 합리적이다.

```ts
const model =
  job.isBrandCritical || job.editCount >= 3
    ? "gpt-image-2.5-sunburst"
    : "gpt-image-2.5-flare";
```

이 코드는 출발점일 뿐이다. 실제 라우팅 조건은 “몇 번 편집했는가”보다 내 평가 데이터에서 어떤 작업이 자주 실패했는지에 따라 바뀌어야 한다.

## 프롬프트보다 중요한 ‘편집 계약’

이미지 생성 프롬프트는 보통 원하는 장면을 묘사한다. 그러나 편집 작업에서는 원하는 변화만큼 **변하지 않아야 할 조건**을 명시해야 한다.

다음처럼 요청을 구성할 수 있다.

> 왼손에 든 머그잔의 색상만 빨간색에서 코발트블루로 변경한다. 인물의 얼굴, 손가락, 자세, 의상, 카메라 구도, 배경, 조명, 그림자, 머그잔의 형태와 로고는 원본과 동일하게 유지한다. 다른 픽셀은 수정하지 않는다.

여기에 세 가지 운영 원칙을 더하면 결과를 관리하기 쉬워진다.

첫째, 한 번에 하나의 의도를 수정한다. 색상과 배경과 포즈를 동시에 바꾸면 어느 지점에서 일관성이 깨졌는지 알기 어렵다.

둘째, 입력 이미지마다 역할을 붙인다. 첫 이미지는 인물의 정체성, 두 번째는 제품 형태, 세 번째는 색감 참고처럼 구분해야 참조 자료끼리 충돌하는 것을 줄일 수 있다.

셋째, 모델 이름과 스냅샷, 프롬프트, 이전 이미지 해시, 수정 대상을 함께 기록한다. 그래야 결과가 달라졌을 때 모델 업데이트 때문인지 입력 변화 때문인지 추적할 수 있다.

이 구조는 프롬프트 모음이 아니라 간단한 버전 관리 시스템에 가깝다. 앞으로의 이미지 도구는 생성 버튼보다 **수정 이력, 비교, 승인, 되돌리기**가 더 중요한 제품이 될 가능성이 크다.

## 데모 대신 ‘편집 드리프트’를 측정하라

새 모델을 평가할 때 예쁜 이미지 10장을 골라 비교하면 거의 모든 모델이 좋아 보인다. 실무 테스트는 일부러 지루하고 반복적이어야 한다.

같은 원본에 다음 명령을 순서대로 적용해 보자.

1. 컵의 색상만 바꾼다.
2. 배경의 벽만 밝게 만든다.
3. 셔츠의 작은 주름만 제거한다.
4. 처음 바꾼 컵 색상을 다시 조정한다.
5. 최종 결과를 첫 원본과 비교한다.

그리고 편집 성공률뿐 아니라 얼굴 유사도, 제품 외곽선 변화, 로고 문자 오류, 배경 이동, 사람이 다시 손봐야 한 시간을 기록한다. 첫 번째 결과가 아니라 다섯 번째 결과에서 원본이 얼마나 남아 있는지가 핵심이다.

이 지표를 **편집 드리프트(edit drift)**라고 부를 수 있다. 생성 모델의 품질을 한 장의 미학으로 평가하던 시대에는 잘 보이지 않았지만, 대화형 편집에서는 가장 중요한 운영 지표 중 하나가 된다.

## 출처 표시는 좋아졌지만 만능은 아니다

OpenAI는 ChatGPT Images 2.5로 생성한 이미지에 C2PA 메타데이터와 보이지 않는 워터마크를 적용한다고 밝혔다. 별도의 안전 평가 문서에는 Google DeepMind의 SynthID를 사용한다고 설명한다. 생성물의 출처를 추적하는 데 유용한 장치다.

하지만 메타데이터는 파일 변환이나 플랫폼 업로드 과정에서 사라질 수 있고, 워터마크 역시 모든 상황에서 출처를 완벽히 증명하는 만능 도장은 아니다. 서비스 개발자는 생성 시각, 사용 모델, 원본과 결과물, 사용자 동의, 검수 기록을 별도로 보관해야 한다. 인물 사진과 브랜드 자산을 다룬다면 기술적 표식보다 권한 관리와 승인 절차가 먼저다.

## 결국 잘 바꾸는 AI는 잘 보존하는 AI다

이미지 생성 모델은 오랫동안 첫인상으로 경쟁했다. 누가 더 화려하고 사실적인 한 장을 만드는지가 중요했다. 그러나 AI 이미지가 마케팅, 커머스, 디자인 협업 안으로 들어갈수록 승부는 다음 장면에서 갈린다.

“이 부분만 조금 고쳐 주세요.”

그 요청을 다섯 번 받아도 인물, 제품, 브랜드의 정체성을 유지할 수 있어야 한다. ChatGPT Images 2.5와 Flare·Sunburst의 등장은 모델 경쟁의 질문이 **무엇을 만들어낼 수 있는가**에서 **무엇을 건드리지 않을 수 있는가**로 바뀌고 있음을 보여준다.

좋은 AI 이미지 모델은 가장 놀라운 그림을 한 번 뽑는 모델이 아니다. 수정할수록 망가지지 않고, 사람이 원하는 방향으로만 움직이는 모델이다. 개발자에게 중요한 것도 최고 점수의 모델을 고르는 일이 아니라, 그 보존 능력을 측정하고 실패를 되돌릴 수 있는 편집 시스템을 만드는 일이다.
